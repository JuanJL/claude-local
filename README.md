## The Agent-Skill Ecosystem

```
SKILLS = Knowledge (what to know)
AGENTS = Behavior (what to do)
COMMANDS = Entry Points (how users trigger)

┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   SKILLS    │───▶│   AGENTS    │◀───│  COMMANDS   │
│  (passive)  │    │  (active)   │    │  (triggers) │
└─────────────┘    └─────────────┘    └─────────────┘
```
